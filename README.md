# Numerical Optimization Methods

University laboratory project focused on implementing and studying unconstrained numerical optimization algorithms in C#.

The project implements several optimization methods from the ground up and visualizes their progression toward the optimum of a given objective function.

## Implemented Methods

### Gradient Descent
Implemented gradient descent using partial derivatives of the objective function and an iterative stopping criterion.

### Steepest Descent with Golden-Section Search
Implemented steepest descent with a variable step size. The step length is determined using the golden-section search method at each iteration.

### Nelder–Mead Simplex Method
Implemented the Nelder–Mead simplex optimization algorithm, including simplex reflection, expansion, contraction, and shrinking operations.
